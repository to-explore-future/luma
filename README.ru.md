## Возможности

- Отдельный ползунок для каждого монитора
- Автоматически выбирает способ: собственная яркость или программное затемнение
- Восстанавливает яркость после сна, пробуждения и переподключения
- Нижний предел 5% — экран никогда не станет полностью чёрным
- Живёт в строке меню

## Установка

1. Скачайте DMG из [Releases](https://github.com/to-explore-future/luma/releases)
2. Перетащите в «Программы»
3. Первый запуск: правый клик → **Открыть** (без нотаризации)

## Примечание

Мониторы с собственной регулировкой меняют подсветку. Остальные используют программное затемнение (изображение становится темнее). Это ограничение монитора.
