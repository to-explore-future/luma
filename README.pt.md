## Funcionalidades

- Um cursor independente por ecrã
- Escolhe o modo automaticamente: brilho nativo ou escurecimento por software
- Restaura o brilho após suspensão, retoma e reconexão
- Limite mínimo de 5%: o ecrã nunca fica totalmente negro
- Vive na barra de menus

## Instalação

1. Descarregue o DMG dos [Releases](https://github.com/to-explore-future/luma/releases)
2. Arraste para Aplicações
3. Primeiro arranque: clique direito → **Abrir** (não notarizado)

## Nota

Ecrãs compatíveis são escurecidos pela retroiluminação. Os restantes usam escurecimento por software (imagem mais escura). É uma limitação do ecrã.
