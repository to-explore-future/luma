## Fonctionnalités

- Un curseur indépendant par écran
- Choisit automatiquement : luminosité native ou gradation logicielle
- Restaure la luminosité après veille, réveil et rebranchement
- Plancher à 5 % : l'écran ne devient jamais noir
- Vit dans la barre des menus

## Installation

1. Télécharger le DMG depuis les [Releases](https://github.com/to-explore-future/luma/releases)
2. Glisser dans Applications
3. Premier lancement : clic droit → **Ouvrir** (non notarié)

## Remarque

Les écrans compatibles sont gradués via le rétroéclairage. Les autres utilisent une gradation logicielle (l'image est assombrie). C'est une limite de l'écran.
