<img src="assets/Luma.iconset/icon_256x256@2x.png" width="160" alt="Luma">

## 功能

- 每块屏幕一条独立滑块，互不影响
- 自动选择控制方式：能原生调光的走原生，不能的走软件调光
- 睡眠唤醒、显示器插拔后自动恢复到之前的亮度
- 亮度下限 5%，不会把屏幕调成全黑
- 常驻菜单栏，点图标即用

## 安装

1. 从 [Releases](https://github.com/to-explore-future/luma/releases) 下载 DMG
2. 拖进「应用程序」
3. 首次打开：右键 → **打开**（未公证）

系统要求：macOS 13 或更高。

## 说明

支持系统原生调光的外接屏（以及内置屏）调的是**真实背光**；不支持的屏幕会退到**软件调光**，观感是压暗画面而不是降低背光。这是显示器本身的限制，不是软件偷懒。
