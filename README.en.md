**Per-display brightness — and it stays where you left it after sleep.**

<img src="assets/Luma.iconset/icon_256x256@2x.png" width="160" alt="Luma">

## Features

- One independent slider per display
- Picks the right backend automatically: native brightness, or software dimming when unsupported
- Restores every display's brightness after sleep, wake, and reconnection
- 5% floor, so you can never black out the screen
- Lives in the menu bar

## Install

1. Download the DMG from [Releases](https://github.com/to-explore-future/luma/releases)
2. Drag it into Applications
3. First launch: right-click → **Open** (not notarized)

## Note

Displays that support native brightness are dimmed at the backlight. Others fall back to software dimming, which dims the image instead. That's a limitation of the display itself.
