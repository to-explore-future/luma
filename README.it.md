## Funzioni

- Un cursore indipendente per schermo
- Sceglie il metodo giusto: luminosità nativa o attenuazione software
- Ripristina la luminosità dopo sospensione, risveglio e ricollegamento
- Limite minimo 5%: lo schermo non diventa mai nero
- Vive nella barra dei menu

## Installazione

1. Scarica il DMG dalle [Releases](https://github.com/to-explore-future/luma/releases)
2. Trascinalo in Applicazioni
3. Primo avvio: clic destro → **Apri** (non notarizzato)

## Nota

Gli schermi compatibili vengono attenuati tramite retroilluminazione. Gli altri usano l'attenuazione software (immagine più scura). È un limite dello schermo.
