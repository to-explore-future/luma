<img src="assets/Luma.iconset/icon_256x256@2x.png" width="160" alt="Luma">

## 功能

- 每塊螢幕一條獨立滑桿
- 自動選擇控制方式：能原生調光的走原生，不能的走軟體調光
- 睡眠喚醒、螢幕插拔後自動恢復
- 亮度下限 5%，不會把螢幕調成全黑
- 常駐選單列

## 安裝

1. 從 [Releases](https://github.com/to-explore-future/luma/releases) 下載 DMG
2. 拖進「應用程式」
3. 首次開啟：右鍵 → **打開**

需要 macOS 13 以上。

## 說明

支援系統原生調光的外接螢幕調的是**真實背光**；不支援的會退到**軟體調光**（壓暗畫面）。這是螢幕本身的限制。
