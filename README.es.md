## Funciones

- Un control independiente por pantalla
- Elige el modo automáticamente: brillo nativo o atenuación por software
- Restaura el brillo tras suspensión, reanudación y reconexión
- Límite inferior del 5 %: la pantalla nunca se apaga del todo
- Vive en la barra de menús

## Instalación

1. Descarga el DMG desde [Releases](https://github.com/to-explore-future/luma/releases)
2. Arrástralo a Aplicaciones
3. Primer inicio: clic derecho → **Abrir** (sin notarizar)

## Nota

Las pantallas compatibles se atenúan por retroiluminación. Las demás usan atenuación por software (se oscurece la imagen). Es una limitación de la pantalla.
