## 기능

- 디스플레이별 독립 슬라이더
- 제어 방식을 자동 선택: 네이티브 밝기가 되면 그것, 안 되면 소프트웨어 디밍
- 슬립/웨이크, 연결 해제 후 자동 복원
- 하한 5% — 화면이 완전히 꺼지지 않습니다
- 메뉴 막대에 상주

## 설치

1. [Releases](https://github.com/to-explore-future/luma/releases)에서 DMG 다운로드
2. 응용 프로그램으로 드래그
3. 첫 실행: 오른쪽 클릭 → **열기** (공증되지 않음)

## 참고

네이티브 밝기를 지원하는 디스플레이는 백라이트를 직접 조절합니다. 지원하지 않으면 화면을 어둡게 하는 소프트웨어 디밍으로 전환됩니다. 디스플레이 자체의 한계입니다.
