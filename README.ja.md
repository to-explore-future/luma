## 機能

- ディスプレイごとに独立したスライダー
- 制御方式を自動選択：ネイティブ輝度が使えればそれ、無理ならソフトウェア調光
- スリープ復帰・接続し直し後に明るさを自動復元
- 下限 5%：画面が真っ暗になることはありません
- メニューバーに常駐

## インストール

1. [Releases](https://github.com/to-explore-future/luma/releases) から DMG をダウンロード
2. 「アプリケーション」へドラッグ
3. 初回起動：右クリック → **開く**（未公証）

## 補足

ネイティブ輝度に対応したディスプレイはバックライトを直接調整します。非対応の場合は画面を暗くするソフトウェア調光になります。これはディスプレイ側の制限です。
